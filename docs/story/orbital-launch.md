# 中等／入軌火箭

團隊接到入軌示範合約。最低要求是把無人測試酬載送入指定軌道，並交付足以確認示範結果的資料。團隊還希望提高承載餘裕，或多帶回一組飛行診斷資料。

## 開局與砍預算

| 觸發 | 玩家可做什麼 | 結果 |
| --- | --- | --- |
| 有立方衛星的合作驗證紀錄 | 接受實驗室借用時段，指定用於酬載介面或資料鏈的測試，或婉拒。 | 套用到一項工作。借用時段有固定期限。 |
| 一般開局 | 用自有測試資源排工。 | 工期與經費按原計畫支出。 |
| 出資方削減第二期經費 | 留承載餘裕、留額外診斷，或兩項都退回基本方案。 | 兩項高規方案原本可能同時排得下，砍預算後需依剩餘經費重排。全選基本方案可把資源留給必要驗證。 |
| 預算未被削減 | 依原預算執行，或主動留出返工餘裕。 | 保留兩項高規方案仍會占用更多測試資源。 |

## 驗證與任務操作

| 觸發 | 玩家可做什麼 | 結果 |
| --- | --- | --- |
| 酬載或資料方案更換 | 檢查哪些介面受影響，補相關分析或重測。 | 送審時採用更新後的證據。 |
| 端到端演練出現資料缺口 | 優先保留必要的軌道確認資料，或投入資源修正後重測以保住額外診斷。 | 放棄額外診斷可縮減工作量。必要證據仍缺時，飛行準備審查退回。 |
| 飛行準備審查通過 | 執行入軌示範，確認軌道和可交付資料。 | 模擬結果決定是否完成最低委託與額外目標。 |

## 結局與後續

| 結局 | 條件 | 後續 |
| --- | --- | --- |
| 完成示範且有額外成果 | 入軌及確認資料達標，並交付額外診斷資料或證明承載餘裕。 | 解鎖登月計畫，額外成果計入聲望。 |
| 完成基本示範 | 入軌及確認資料達標。 | 解鎖登月計畫。 |
| 已發射、示範未完成 | 未達指定軌道或缺少確認資料。 | 結算指出缺口，可重玩。 |
| 未發射 | 必要工作無法在工期與經費內完成。 | 結算指出哪項證據缺失或哪個資源先用完。 |

完成示範且準時交付成果，登月案可談較早的預付款。完成示範且保留完整端到端驗證紀錄，合作方可提供一個額外的整合支援時段。兩項履歷可同時取得。
